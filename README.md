# Artline Motors Calculator Bot

MVP Telegram-бота для расчета покупки автомобиля у дилера в США до Ростова-на-Дону или Москвы.

## Что считает

- стоимость авто у дилера;
- выкуп у дилера `1.5%`;
- комиссия партнера: `$3500` до `$100000`, `$4500` выше `$100000`;
- доставка по США до порта NY;
- океан: `$6500` в составе 3 машин или `$7500` в составе 2 машин;
- вывод USDT `1.5%` от суммы выше;
- брокер РФ `$1000`;
- таможенная пошлина для физлица;
- таможенный сбор за оформление по ставкам 2026 года;
- утильсбор по ставкам 2026 года;
- лаборатория РФ `80000 ₽`;
- доставка до Ростова-на-Дону `30000 ₽` или Москвы `80000 ₽`;
- твоя комиссия в рублях.

## Запуск локально

```bash
cp .env.example .env
npm test
BOT_TOKEN=123456:token npm start
```

На Windows PowerShell:

```powershell
$env:BOT_TOKEN="123456:token"
npm start
```

## Деплой на Bothost

1. Создать Telegram-бота через `@BotFather` и получить токен.
2. Загрузить проект на Bothost через Git или веб-интерфейс.
3. Указать `BOT_TOKEN` в переменных окружения Bothost или загрузить `.env`.
4. Команда запуска: `npm start`.

Бот работает через long polling, без webhook и без внешних npm-библиотек. Это проще для MVP и подходит для небольшого внутреннего калькулятора.

## Курсы валют

По умолчанию бот берет USD/RUB и EUR/RUB с официального XML-сервиса ЦБ РФ:

`https://www.cbr.ru/scripts/XML_daily.asp`

Для расчета бот всегда добавляет к курсу ЦБ РФ `+5%`. В сообщении пользователю бот показывает и итоговый курс для расчета, и базовый курс ЦБ.

Если сервис недоступен, можно задать fallback-переменные:

```env
USD_RUB=92
EUR_RUB=100
```

## Источники ставок

- Пошлины для авто физлиц: Решение Совета ЕЭК от 20.12.2017 N 107, приложение N 2.
- Утильсбор: Постановление Правительства РФ от 26.12.2013 N 1291 в редакции, действующей в 2026 году.
- Таможенные сборы за оформление: Постановление Правительства РФ от 28.11.2024 N 1637 с изменениями от 23.10.2025 N 1638, ставки с 01.01.2026.

## Важное ограничение MVP

Сейчас расчет сделан для физлица и автомобиля категории M1 с ДВС, покупка у дилера в США. Электро/гибриды, аукционы США, Китай и коммерческий ввоз вынесены в следующие этапы.
